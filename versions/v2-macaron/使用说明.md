## 部署步骤

1. 清空仓库 `handsomeZR-netizen/handsomeZR-netizen` 的 main 分支旧内容；
2. 把压缩包内所有文件（含隐藏目录 `.github`）放入仓库根目录并推送：

   ```bash
   git add -A
   git commit -m "redesign: pastel profile v2"
   git push origin main
   ```

3. 推送会自动触发贪吃蛇 workflow（也可在 Actions 手动 Run workflow），蛇图生成到 `output` 分支；
4. 第一次生成前，蛇的位置会暂时显示加载失败，跑完后刷新即可。

## 自定义提示

- 想增删技术栈标签：直接改 `assets/stack.svg`，每个胶囊是一组 `<rect> + <circle> + <text>`，胶囊宽度约 = 36 + 字符数 × 7；
- 精选项目想换：编辑 README 中 Featured Projects 的 `<table>` 单元格即可，领域小徽章颜色——EdTech 青绿 / Research 紫 / CV·RL 灰蓝 / Frontend 柔橘；
- 统计卡颜色都在 README 的 URL 参数里，可直接改十六进制值；
- 所有 SVG 动画已适配 `prefers-reduced-motion`。
